# Утилита тестирования требований с помощью ИИ

Автоматически считывает файлы с требованиями из папки `input/` (рекурсивно,
включая все вложенные папки), отправляет их содержимое в LLM (OpenAI-совместимый
API, модель **qwen3.8**, `temperature=0.1`, `max_tokens=200000`) для проведения
тестирования качества требований, и сохраняет результат в файл вида:

```
output/тестирование требований_2026-10-28_15-30-00.md
```

## Состав

| Файл | Назначение |
|---|---|
| `req_tester.py` | основная утилита |
| `prompt.txt` | промпт-инструкция для ИИ (критерии качества требований и формат отчёта) — редактируйте под себя |
| `requirements.txt` | зависимости Python |
| `input/` | папка с файлами требований (пример: `input/example/requirements_sample.md`) |
| `output/` | создаётся автоматически, туда складываются отчёты |

## Поддерживаемые форматы входных файлов

`.doc`, `.docx`, `.md`, `.pdf`, `.txt`, `.xlsx`, `.xml`, `.json`

- `.docx` — python-docx (абзацы + таблицы)
- `.doc` — LibreOffice (`soffice`), при его отсутствии — fallback через olefile
- `.pdf` — pypdf
- `.xlsx` — openpyxl (все листы)
- `.xml` / `.json` — извлечение текстовых значений тегов/атрибутов/полей
- `.txt` / `.md` — прямое чтение с определением кодировки (utf-8 / cp1251)

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
export OPENAI_API_KEY="sk-ваш-ключ"
# необязательно, если используется совместимый шлюз (DashScope, OpenRouter, vLLM…):
export OPENAI_BASE_URL="https://адрес-шлюза/v1"
# необязательно, если имя модели отличается:
export QWEN_MODEL="qwen3.8"

python req_tester.py
```

Полезные ключи:

```
--input-dir PATH    папка с требованиями (по умолчанию ./input)
--output-dir PATH   папка результатов (по умолчанию ./output)
--prompt-file PATH  файл промпта (по умолчанию ./prompt.txt)
--model NAME        модель (по умолчанию qwen3.8)
--temperature F     температура (по умолчанию 0.1)
--max-tokens N      максимум токенов ответа (по умолчанию 200000)
--per-file          отдельный запрос к ИИ на каждый файл
                    (по умолчанию все файлы отправляются одним запросом)
```

## Гарантия «обработка только после полного ответа ИИ»

В функции `ask_ai()` вызов `client.chat.completions.create(...)` выполняется в
**синхронном (не streaming) режиме** (`stream=False`). Программа блокируется на
этом вызове до тех пор, пока модель не отдаст ответ целиком. Только **после**
возврата полного объекта `completion` начинается его разбор
(`choices[0].message.content`) и запись в файл результата. Никакая часть
ответа не обрабатывается и не сохраняется до завершения генерации.
